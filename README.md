## Featured Project

### [MalwareDelta](https://github.com/intx5/MalwareDelta)

**Semantic malware sample diffing and evolution analysis in Rust.**

MalwareDelta is built around a simple question:

> **What changed between two malware variants from an analyst's perspective?**

It can compare and analyze:

* PE structure and sections
* Imports
* ASCII and UTF-16 strings
* IOC / C2 infrastructure
* Section entropy
* capa capabilities
* FLOSS decoded strings
* Sample similarity
* Malware-family sample clusters
* Artifact provenance / evidence

It provides:

* Terminal reports
* JSON output
* Standalone HTML reports
* Interactive TUI
* Directory-level clustering

The core analyzer is written in **Rust** and does not require external malware-analysis tools.
